# AegisLab chemical safety evaluation

This directory contains a transparent, synthetic/demo benchmark for the first
organic-solvent protocol pack. It covers normal procedures, missing PPE,
ventilation gaps, waste-stream gaps, incompatibility, equipment boundaries,
ignition-source anomalies, ambiguity, and incomplete evidence.

Run from the repository root:

```bash
python3 eval/run_eval.py
```

The command writes `predictions.jsonl`, `predictions.csv`, `summary.json`, and
`summary.md` under `eval/results`. The checked-in result is generated by the
script; it must be read as an offline synthetic baseline, not field performance,
an institutional safety certification, or a real accident-rate claim.

The dataset is intentionally reviewable. Each case contains the SOP text,
scenario, expected hard-rule findings, expected action, severity, and expected
control mapping. The evaluator computes finding precision/recall/F1, severe/high
risk recall, false-positive rate on clean cases, control matching, evidence hash
verification, elapsed review time, manual-review rate, override rate, and offline
availability.

`fixtures/same_domain_cases.jsonl` and `fixtures/incident_drills.json` are kept
as small API fixtures. They are synthetic and safe to commit.
