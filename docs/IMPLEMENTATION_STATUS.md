# 网页端重构 · 本次实际实现与边界

## 交付形式与优先级

交付形式统一为浏览器网页系统；最终使用者打开网址即可访问。不要做 Electron、Tauri、原生桌面软件、移动端或安装型 PWA。此前方案与参考图中的移动复核、手机底部导航、移动页面验收不再属于需求。

保留蓝白浅色视觉；主导航“空间、计划、协同、资料、资源”，底部设置。不是把所有功能卡片铺满首页，不设置比赛演示模式或自动批准按钮。比赛视频独立录制。

实现基线为 `9320dea697f370a40eca422395fa407b48486357`。本目录与网页源码、后端、测试和锁文件一同纳入 Git 提交；该基线 SHA 不是新版代码提交。当前版本以所在分支的 Git 历史为准，不需要另行下载压缩包或应用补丁。

## 尚未达到完整终版的部分

这里不能把“已有可操作界面”当作整份产品文档全部完成。

**三维与视觉最终验收：** 已编写真实 Three.js 实现，不是使用生成图片充当背景；当前测试环境禁用 WebGL，无法确认真实 GPU 上的构图、选取射线、遮挡、标签碰撞、阴影、帧率及动画。需要在本地电脑浏览器验收并继续打磨模型资产。现有模型为程序化模型，不承诺与高精度概念图逐像素一致。

**完整关系知识：** 当前图主要覆盖计划、资源、资料，尚不是全量化学实体、规则、来源、步骤、控制、审批本体，也没有独立的图数据库或通用知识图谱推理。

**业务判定范围：** 当前资源约束可执行且有测试，但不等同于经过专家认证的化学安全规则包；已有 SOP 文本规则仅辅助预审，不能用于声称全域化学安全或事故下降。三维不模拟化学反应、流体、气体扩散或现场传感器遥测。

**身份与协作：** 已有任务与操作记录，但未完成机构登录、多用户独立账号、角色权限、双人签署、通知投递、隔离租户。现有工作区令牌用于本地/受控环境单负责人访问，不能当作完整多人安全权限体系。

**文档与证据治理：** 当前保存提取文本、来源、规格与时间，没有完整二进制原文存储、逐页版面坐标、扫描件 OCR、签名验证、规则发布工作流或外部来源同步。导入后定位是提取后文本行，不伪造 PDF 页内坐标。

**复核语义：** 新界面记录资源前置条件复核，不直接发出“实验开工许可”。例外授权、组织审批策略和全量安全签核仍未接入新网页。禁止为了录视频添加绕过规则的一键通过。

**运维与历史：** 数据库持久化、事件和复核依据指纹已经实现；尚无所有版本完整快照恢复、迁移向导、自动备份调度、后台长期任务、自动到期通知、云端部署验证。旧数据库与新库是隔离存储，不会自动转换旧审查为新计划。

**测试边界：** 未测试真实模型服务、公开网络生产部署、全部浏览器版本、长时间压力、完整无障碍审计和真实实验室试用。不把测试数据写成竞赛应用效果。
